# Write Lecture Notes

Create rigorous, self-contained notes at the course's level. Follow the instructor's intellectual priorities and established style. Use current authoritative course sources; never substitute a stale mirror. Explicit instructor requirements and established course conventions take precedence over these defaults.

## Working principles

- For introductory graduate statistics, prioritize intuition and a coherent road map: questions, mechanisms, assumptions, consequences, and connections to later readings. Graduate level does not require exhaustive technical narration. Preserve essential reasoning and carefully chosen examples; clarify through better structure, comparisons, and visuals before adding prose.
- Match the requested scope. A caption edit does not trigger a full pedagogical audit; a skill-only update does not change lecture files. Extend student companions only when requested. Use one agent by default.
- Before substantive revision, map prerequisites, teaching questions, examples, and visual needs. Choose the sequence by conceptual dependency, keeping results, interpretation, and proofs connected. Apply course conventions within scope; detailed guidance lives below.
- Read only relevant reference sections; search headings and labels before long reads. Combine checks into one pass and reuse verified sources, assets, and results while inputs remain unchanged. Verify changed claims and dependencies, compile, and inspect affected pages. Broaden for shared changes or unresolved concerns. Keep planning maps compact and outside student notes.
- Deliver the checked notes and identify remaining issues accurately. Do not equate compilation, a figure count, or a source scan with mathematical or pedagogical completeness.
