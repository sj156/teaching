# Create Homework

Design concise instructor-facing assignments grounded in the course notes. Preserve logistics, points, notation, and the authoritative working folder; do not invent deadlines. Verify named lecture results rather than guessing from numbering.

Choose theory, data, and computation by their teaching purpose. Keep hints distinct from assessed work and solutions separate; create solutions only when requested. Follow the course notation and established LaTeX style; detailed conventions live in the references below.

## Work proportional to the request

- Read the target and necessary lecture dependencies; search headings or symbols before long reads. Load only relevant reference sections and reuse context unless it changed.
- Apply standards within the requested scope and affected dependencies. A local correction does not trigger a full audit; a whole-artifact request still requires completing that scope. For a new assignment, use the full-audit index to organize the same verification pass.
- Use one agent by default. Delegate only when requested or needed to resolve consequential uncertainty, with a narrow question rather than a duplicate whole-document review.
- Combine overlapping checks; reuse verified results, citations, figures, and builds while their inputs remain unchanged. Verify changed content and dependencies, compile rendered artifacts, and inspect affected pages; broaden for shared styling, reflow, or unresolved concerns. Repeat only for new changes or failed checks.
- Stop when the work and applicable checks are complete. Report limitations and file locations briefly. Create no extra reports, companions, or experiments unless requested or needed for the deliverable.
